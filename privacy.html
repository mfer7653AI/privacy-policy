개인정보보호 및 보안 규정 준수

개인정보처리방침 (Privacy Policy)

시행일자: 2026년 10월 18일

Antigravity Workspace Client(이하 '서비스')는 정보주체의 자유와 권리 보호를 위해 「개인정보 보호법」 및 Google API 서비스 사용자 데이터 정책(Google API Services User Data Policy)을 준수하며, 이용자의 개인정보를 보호하고 관련 고충을 신속하게 처리하기 위하여 다음과 같이 개인정보처리방침을 수립·공개합니다.

1. 개인정보의 처리 목적

서비스는 다음의 목적을 위해서만 개인정보를 처리합니다. 처리하고 있는 개인정보는 다음 목적 이외의 용도로는 절대 이용되지 않습니다.

  • 개인 일정 및 작업 자동화: 구글 캘린더 일정 조회, 중요 마감 및 발표 일정의 자동 캘린더 등록.
  • 이메일 트리아지 및 라벨링: 수신된 이메일의 중요도 분석, 스팸/홍보성 메일 분류, 일일 업무 보고서 작성 및 발송.

2. 처리하는 개인정보의 항목 및 접근 권한

서비스는 이용자가 직접 승인한 Google OAuth 2.0 권한 범위 내에서만 데이터를 처리합니다.

  • Google 계정 정보: 기본 프로필 및 이메일 주소.
  • Gmail 데이터: 이메일 헤더(발신자, 수신자, 제목, 일시), 메일함 라벨, 메시지 본문(트리아지 및 요약용).
  • Google Calendar 데이터: 캘린더 이벤트 생성, 수정, 삭제 및 일정 조회.

3. 개인정보의 안전성 확보 조치 (철저한 보안 원칙)

  • 로컬 머신 격리 보관: 발급된 OAuth 자격증명 및 리프레시 토큰은 이용자의 개인 기기(Mac) 내에만 저장되며, 파일 시스템 권한(chmod 600)을 통해 외부 프로세스 및 타인의 접근을 원천 차단합니다.
  • 전송 구간 암호화: Google API 서버와의 모든 통신은 최신 TLS 1.3 보안 프로토콜을 적용하여 전 구간 암호화됩니다.
  • 외부 데이터베이스 미저장: 서비스는 별도의 외부 클라우드 DB나 원격 서버에 이용자의 이메일 본문이나 캘린더 일정을 일체 전송하거나 영구 저장하지 않습니다.

4. 개인정보의 제3자 제공 및 외부 위탁 금지 (Zero-Sharing 원칙)

서비스는 이용자의 개인정보를 어떠한 경우에도 제3자에게 제공, 판매, 위탁하거나 외부 인공지능(AI) 모델의 재학습 데이터로 활용하지 않습니다.

5. Google API 사용자 데이터 정책 준수 선언

Antigravity Workspace Client의 Google API 사용 및 다른 앱으로의 정보 이전은 제한적 사용 요건(Limited Use Requirements)을 포함한 Google API 서비스 사용자 데이터 정책을 철저히 준수합니다.

6. 개인정보의 파기 및 권한 철회

이용자는 언제든지 Google 계정 보안 센터에서 서비스의 접근 권한을 즉시 철회할 수 있으며, 권한 철회 시 로컬에 저장된 자격증명 토큰은 즉시 영구 파기됩니다.
